# ЭкоКод

**ЭкоКод** — интерактивный игровой симулятор цифровой школы безопасности в лесу для школьников 10–15 лет. Пилотная версия ориентирована на ЯНАО.

## Что внутри

- три последовательных игровых сценария: поход, рыбалка в тундре и семейный пикник;
- пять решений в каждом сценарии;
- визуальная сцена с анимацией дыма, огня, искр и изменением уровня риска;
- интерактивные точки осмотра и дополнительные действия;
- XP, серия безопасных решений и достижения;
- профиль без регистрации;
- локальное хранение имени и прогресса.

## Технологии

- HTML5
- CSS3
- JavaScript без фреймворков
- GitHub Pages через GitHub Actions

Проект намеренно собран как лёгкий статический сайт: для работы в браузере не нужны сервер, база данных или внешние API.

## Локальный запуск

Можно открыть `index.html` напрямую в браузере. Для локального HTTP-сервера подойдёт любой простой статический сервер.

## Безопасность

В production-входе используются локальные CSS/JS, строгая CSP без `unsafe-inline`, отключены плагины и внешние подключения. Пользовательские данные не отправляются на сервер; имя ограничено 24 символами и хранится только в `localStorage`.
