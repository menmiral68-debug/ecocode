# ЭкоКод

**ЭкоКод** — интерактивный учебный симулятор безопасного поведения на природе для школьников 10–15 лет. Пилотная версия разработана с учётом контекста Ямало-Ненецкого автономного округа.

## Назначение

Проект переводит правила пожарной безопасности из формата обычной памятки в короткие игровые ситуации. Пользователь наблюдает за обстановкой, выбирает решение и получает объяснение результата.

В текущей версии доступны три сценария:

1. **Поход с друзьями** — оценка места, условий и действий при обнаружении возгорания.
2. **Рыбалка в тундре** — изменение погоды, ветер, ограничения и сообщение о дыме.
3. **Семейный пикник** — предварительная проверка условий, организация безопасного пространства и действия при появлении дыма.

Каждый сценарий содержит пять решений. За безопасные ответы начисляется опыт; завершённые сценарии, серия решений и достижения сохраняются в браузере.

## Структура проекта

```text
index.html
css/styles.css
js/app.js
.nojekyll
.gitignore
README.md
```

Проект намеренно не содержит React, Vite, сборщиков, npm-зависимостей или серверной части. В рабочей версии браузеру нужны только HTML, CSS и JavaScript.

## Технические особенности

- семантическая HTML-разметка;
- адаптивная вёрстка для компьютеров и мобильных устройств;
- CSS-анимации сцены и состояния интерфейса;
- игровая логика на чистом JavaScript;
- сохранение прогресса через `localStorage`;
- отсутствие внешних API и аналитических сервисов;
- динамический текст добавляется через DOM API, без вставки пользовательских данных в HTML;
- Content Security Policy без `unsafe-inline` для скриптов;
- ограничение длины имени пользователя до 24 символов;
- корректная работа при недоступном `localStorage` — игровой интерфейс остаётся доступным.

## Локальный запуск

Это статический сайт. Для проверки достаточно открыть `index.html` в браузере. Для полноценного тестирования через HTTP можно использовать любой локальный статический сервер.

## Публикация

Репозиторий подготовлен для ручной публикации через GitHub Pages. Конфигурация Pages намеренно не входит в исходный проект: способ публикации выбирается владельцем репозитория в настройках GitHub.

## Данные и приватность

Проект не отправляет имя, результаты игры или игровой прогресс на внешний сервер. Данные профиля сохраняются только локально в браузере пользователя. Очистка данных сайта удаляет локальный прогресс.

## Статус

Текущая версия — конкурсный MVP. Архитектура специально оставлена простой: это позволяет быстро загрузить сайт, проверить его работу и в дальнейшем расширять сценарии без зависимости от серверной инфраструктуры.
